🚀 About the Project

AWS Zero to Professional is an independent cloud computing education project developed under SAMCLOUD.

The platform aims to make AWS and cloud infrastructure easier to understand through structured learning, practical demonstrations, interactive dashboards and a browser-based AWS environment simulator.

Whether you are starting with zero cloud knowledge or preparing to explore professional CloudOps concepts, this platform provides a structured learning journey.

🌐 Explore the Platform

"OPEN THE LIVE AWS LEARNING PLATFORM →" (https://samcloudops.github.io/AWS-Zero-to-Professional/)

Explore the learning dashboard, AWS service directory, interactive lessons and simulated cloud environment.

🎯 Project Objectives

- Understand cloud computing from the fundamentals.
- Learn Amazon Web Services step by step.
- Explore cloud infrastructure and architecture.
- Understand how applications connect to cloud services.
- Practise resource configuration in a safe simulator.
- Develop foundational Cloud Engineer and CloudOps knowledge.

🖥️ AWS Console Simulation

The project aims to provide an educational environment resembling the AWS Management Console.

Services covered

AWS Service| Learning concepts
Amazon EC2| Instances, operating systems and storage
Amazon S3| Buckets and object storage
Amazon VPC| Virtual networks and subnets
AWS IAM| Users, roles and permissions
Amazon RDS| Relational database concepts
Amazon DynamoDB| NoSQL database concepts
AWS Lambda| Serverless computing
Amazon CloudFront| Content delivery
Amazon Route 53| DNS and hosted zones
Amazon CloudWatch| Metrics, logs and alarms
Elastic Load Balancing| Traffic distribution
Amazon EBS| Block storage

Simulation disclaimer: These are educational demonstrations. The simulator does not create actual AWS resources or connect to a real AWS account.

📱 Run Locally Using Termux

Clone the repository:

git clone https://github.com/samcloudops/AWS-Zero-to-Professional.git

cd AWS-Zero-to-Professional

Start the local development server:

python -m http.server 8080

Open in your browser:

http://127.0.0.1:8080

🔒 Security and Simulation Notice

This project is designed for educational purposes.

- Simulated resources are not real AWS infrastructure.
- No actual cloud servers or databases are provisioned.
- No real AWS credentials are required.
- Never enter passwords, access keys or secret keys into demonstration forms.
- Resource data is stored locally in the browser.
